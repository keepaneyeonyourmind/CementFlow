# Учебный API CementFlow

Это контракт учебной версии; данные и цены демонстрационные. API не выполняет авторизацию и не предназначен для публикации в интернете или обработки настоящих персональных данных.

Все запросы и ответы используют JSON и UTF-8. Цена и сумма — числа в рублях с двумя знаками после запятой. Заказ содержит один товар; количество целое, от 1 до 10000. Цену выбирает сервер из каталога и сохраняет на момент заказа. Успешное создание возвращает HTTP 201, остальные успешные запросы — 200. Ошибки возвращаются в виде `{"message":"понятное описание"}`: 400 — неверные данные, 404 — товар или заказ не найден, 409 — недопустимый переход статуса.

## Каталог

`GET /api/products` — массив объектов:

```json
[{"id":1,"name":"Цемент М400 (учебный)","unit":"мешок","price":420.00}]
```

## Заказы

`POST /api/orders`:

```json
{"productId":1,"quantity":2,"customerName":"Ирина","phone":"+79001234567","address":"Учебная улица, 1"}
```

Сервер возвращает созданный заказ, см. формат ниже. Все поля обязательны; имя и телефон — от 1 до 100 символов, адрес — от 1 до 300 символов после удаления пробелов по краям. Телефон здесь учебная строка, не проверяется как настоящий номер. Максимальное количество 10000 ограничивает размеры примера.

`GET /api/orders` — список заказов, новые сначала. `GET /api/orders/{id}` — один заказ:

```json
{"id":1,"productId":1,"productName":"Цемент М400 (учебный)","unit":"мешок","quantity":2,"unitPrice":420.00,"total":840.00,"customerName":"Ирина","phone":"+79001234567","address":"Учебная улица, 1","status":"WAITING","driverName":null}
```

## Доставка

`POST /api/orders/{id}/assign` с телом `{"driverName":"Алексей"}` — назначить водителя заказу в статусе `WAITING` и перевести его в `ASSIGNED`; имя обязательно, максимум 100 символов.

`POST /api/orders/{id}/status` с телом `{"status":"IN_TRANSIT"}` — изменить статус на следующий. Допустимы только `ASSIGNED → IN_TRANSIT` и `IN_TRANSIT → DELIVERED`. Назначение в `ASSIGNED` выполняется отдельным запросом выше. Повтор, пропуск и обратный переход возвращают 409. Сервер блокирует строку заказа на время изменения, чтобы одновременные запросы не перезаписывали друг друга.

Словарь: `WAITING` — ожидает, `ASSIGNED` — назначена, `IN_TRANSIT` — в пути, `DELIVERED` — доставлена.
