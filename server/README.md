# Сервер CementFlow

Учебный сервер на Kotlin, Spring Boot и PostgreSQL: каталог демонстрационных товаров, оформление заказа с одним товаром и ручное изменение статуса доставки. Описание запросов: [API.md](API.md). Коды и цены не связаны с настоящими товарами и услугами компании. Настоящей авторизации нет; сервер предназначен только для локальной учебной демонстрации.

## Что понадобится

- JDK 25 для сборки (можно использовать встроенную в Android Studio Java, если установлена версия 25); целевая версия классов JVM — 17. Сборка и локальный запуск с Java из Android Studio проверены.
- Учебная база PostgreSQL и отдельный пользователь с правами на создание таблиц и изменение данных. Установка PostgreSQL — системное действие и требует отдельного согласия.
- Доступ в интернет при первой сборке: Gradle Wrapper загружает Gradle 9.6.0 и проектные зависимости.

В `build.gradle.kts` указаны версии библиотек. Wrapper запускает нужный Gradle без глобальной установки. Реальные пароли не сохраняйте в файлы проекта и историю Git.

## Подготовка схемы и данных

После согласованной установки и настройки учебной базы примените `sql/schema.sql`, затем `sql/demo-data.sql` через удобный клиент PostgreSQL. Например, с уже настроенным `psql`:

```powershell
psql -h localhost -U <имя_пользователя> -d <имя_базы> -f sql/schema.sql
psql -h localhost -U <имя_пользователя> -d <имя_базы> -f sql/demo-data.sql
```

Подставьте имена базы и пользователя; при запросе введите пароль интерактивно. Не используйте реальные персональные данные: записи не защищены авторизацией. Скрипты создают таблицы при отсутствии и добавляют товары с фиксированными идентификаторами, не удаляя существующие заказы.

## Запуск в PowerShell

Из папки `server` в текущем окне PowerShell задайте адрес базы и учётные данные, подставив локальные значения:

```powershell
$env:CEMENTFLOW_DB_URL = 'jdbc:postgresql://localhost:5432/<имя_базы>'
$env:CEMENTFLOW_DB_USER = '<пользователь_базы>'
$env:CEMENTFLOW_DB_PASSWORD = '<пароль_базы>'
.\gradlew.bat bootRun
```

Если системный `JAVA_HOME` не настроен, можно указать его только для текущего окна, например `$env:JAVA_HOME = 'C:\Users\Administrator\AppData\Local\Programs\Android Studio\jbr'`. После завершения закройте окно PowerShell: переменные сеанса будут удалены. Серверу нужны работающая база и заполненные переменные окружения.

## Проверки

`.\gradlew.bat test` — модульные тесты правил заказа и доставки; `.\gradlew.bat build` — сборка и тесты. Для проверки полного сценария необходима подготовленная PostgreSQL. Сборка и модульные тесты прошли. API, подключение к PostgreSQL и последовательность статусов проверены; проверочные заказы удалены.

## Настройка на этом компьютере

С согласия пользователя установлена PostgreSQL 17.12, создана база `cementflow_demo` и отдельная роль `cementflow_app`; схема и демонстрационные товары загружены. Пароли администратора и приложения защищены Windows для текущей учётной записи и находятся вне проекта в `%LOCALAPPDATA%\CementFlow`. Их нельзя перенести на другую учётную запись без перенастройки. Сервер слушает только `127.0.0.1`; доступ с телефона не настроен.

Для текущей учётной записи Windows и Android Studio можно из папки `server` запустить `powershell -ExecutionPolicy Bypass -File .\run-local.ps1`. Скрипт читает локальный зашифрованный пароль, задаёт переменные только своему процессу и запускает сервер. Запуск скрипта и чтение каталога проверены. Первой сборке нужен доступ Gradle к библиотекам.
