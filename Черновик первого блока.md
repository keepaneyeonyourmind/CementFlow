# CementFlow — первый блок: состояние и данные

Начальный черновик уточнён по фактически созданному прототипу. Учебные варианты требуют обсуждения с командой; они не являются производственными ценами или рецептурами.

## Сценарии

```text
Главный экран
├─ Калькулятор → выбор марки и объёма → учебный результат
└─ Заказы и доставка
   ├─ Клиент → каталог → заказ одного товара → просмотр статуса
   └─ Сотрудник → общий список → назначение водителя → смена статуса
```

В приложении роли переключаются без авторизации, список общий. Экран заказа показывает загрузку и ошибки связи; при неопределённом результате отправки предлагает обновить список перед повтором.

## Данные и правила

| Сущность | Реализованные поля и правила |
| --- | --- |
| Товар | Идентификатор, название, единица, учебная цена; три демонстрационных товара. |
| Заказ | Один товар, целое количество 1–10000, имя, телефон, адрес, цена товара и итог; цену и сумму рассчитывает сервер. |
| Доставка | Заказ, учебное имя водителя; ожидает → назначена → в пути → доставлена; сервер отклоняет неверные переходы. |
| Расчёт | Марка М200/М300/М400 и положительный объём, условная цена 4000/5000/6000 ₽/м³, результат округлён до копеек. |

Контракт запросов и ответы описаны в [API сервера](server/API.md), SQL-схема находится в `server/sql/`. Калькулятор не создаёт заказ и не рассчитывает рецептуру.

## Дизайн и оставшаяся работа

Использована палитра Obsidian: `#96171A`, `#8F98A3`, `#454545`, `#EEF0F1`, `#E9EAED`. Добавлены полупрозрачные поверхности, градиенты и небольшая анимация по пожеланию пользователя; после этой правки сборка и тесты прошли, визуальный осмотр обновлённого оформления ещё нужен.

Команде предстоит обсудить название «СтройПоток», учебные данные, распределение ответственности и сценарий защиты. Физический телефон, настоящая авторизация и безопасный удалённый доступ не настроены. Подробная передача работы — [HANDOFF.md](HANDOFF.md).
